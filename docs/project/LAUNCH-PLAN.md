## الحقيقة في سطر

البرمجة شبه جاهزة، والقطعة التي كانت تمنع الإقلاع — **لا طريق لإيصال رمز التحقّق** — صارت موجودة: الرمز يُرسَل على واتساب، إمّا عبر الـ Cloud API الرسمي أو عبر بوت يحمل حسابًا مربوطًا (`services/whatsapp-bot`). الباقي حسابات تُشترى **ورقم هاتف مخصّص للبوت يُمسَح رمزه مرّة واحدة**.
