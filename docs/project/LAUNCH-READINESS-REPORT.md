## ١. الحكم في سطر

**البرمجة لم تعد الحاجز.** الدورة الكاملة — من إنشاء حساب إلى ظهور منشأة للعامّة — تعمل من
طرفها إلى طرفها على حزمة حقيقية، بصفر فشل. ما يمنع الإطلاق **خمسة أشياء تُشترى أو تُقرَّر**،
أرخصها رقم هاتف.

| | |
|---|---|
| جاهزية برمجية | **عالية** — ١٩ فحصًا آليًا، كلّها خضراء |
| جاهزية تشغيلية | **منخفضة** — لا نطاق ولا استضافة ولا بيانات حقيقية |
| أقرب حاجب يُزال | رقم واتساب مخصّص + مسح رمز = **صفر تكلفة** |

## ٢. الدورة الكاملة، كما جرت فعلًا

`scripts/e2e-android.sh` على حزمة معزولة (قاعدة بياناتها وتخزينها ومنافذها الخاصّة):

| # | المرحلة | النتيجة |
|---|---|---|
| ١ | تهيئة قاعدة بيانات وتخزين من الصفر | ✅ |
| ٢ | إقلاع Django بالـHTTP وبالـWebSocket | ✅ |
| ٣ | **الحزمة المتّصلة — ٢٩ حالة**: تسجيل حساب جديد بثلاث خطوات، استعادة كلمة مرور، إلغاء الجلسات، اكتشاف وبحث وتصفية وترقيم، تفاصيل منشأة ومواعيدها | ✅ |
| ٤ | **المالك يرفع منشأة** باسمها وهاتفها وموقعها ومواعيدها وصورتها، ويُرفَض تقديمها قبل المستندات، ثم يُقدّمها بعدها | ✅ |
| ٥ | **مشغّل يفتح المستند ويوافق** في لوحة التحكّم الحقيقية (بناء إنتاجي، متصفّح حقيقي) | ✅ |
| ٦ | **المنشأة تظهر للعامّة** بصورتها، في الاكتشاف وفي صفحتها | ✅ |
| ٧ | **عزل التخزين**: الصورة العامّة تُقرأ بلا اعتماد (200)، المستند الخاصّ يُرفض (403)، ولا يمكن سرد مفاتيح الدلو العام | ✅ |

**`failures=0`.**

ثلاث حقائق تستحقّ الانتباه في هذه الدورة:

- **لا شيء مُحاكى.** قاعدة PostGIS حقيقية، تخزين MinIO حقيقي، لوحة تحكّم مبنيّة بناءً إنتاجيًّا،
  ومتصفّح حقيقي يضغط الأزرار.
- **التقديم يُرفض قبل المستندات** — القاعدة محفوظة في الخادم لا في الواجهة.
- **المستندات لا تُقرأ بلا إذن أبدًا**، وهذا مُثبَت بطلب مجهول في كل تشغيل.

## ٧. الطريق إلى الإطلاق

1. **رقم للبوت** — صفر تكلفة، ويفتح التسجيل كلّه. *ابدأ هنا.*
2. نطاق + استضافة + S3 → نشر تجريبي → دورة كاملة برسالة حقيقية.
3. بيانات الصيدليات، وسياسة الخصوصية والشروط، وبريد الدعم.
4. حساب Play → تجربة مغلقة → نشر عام.

**قبل كل دمج أو نشر: `bash scripts/verify.sh`.**
