## كيف تُعاد هذه الاختبارات

```bash
# الخادم
docker exec local-api sh -lc 'cd /app && uv run pytest -q'

# الموقع
pnpm --filter @servacode/public-web typecheck
pnpm --filter @servacode/public-web lint
pnpm --filter @servacode/public-web build

# لوحة التحكّم
pnpm --filter @servacode/admin lint
pnpm --filter @servacode/admin typecheck
pnpm --filter @servacode/admin test
pnpm --filter @servacode/admin build

# المشترك
pnpm --filter @servacode/design-tokens check
bash scripts/check-openapi-drift.sh
python infrastructure/quality/source_security.py
python infrastructure/quality/release_blockers.py

# التطبيق (في CI فقط — Google Maven محجوب محليًا)
cd apps/android && ./gradlew assembleLocalDebug testLocalDebugUnitTest lintLocalDebug
```
