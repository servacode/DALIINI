# خطة فحص الجاهزية قبل الإطلاق — دليني

**الهدف:** نشغّل المنصة كأنها تعمل فعلاً، من أول يوم: الأدمن يجهّز الدليل، والزائر يتصفّح، والمستخدم
يسجّل ويقيّم، وصاحب المنشأة يسجّل منشأته ويديرها، والأدمن يراجع ويشغّل. ونجرّب ما يمكن أن يخرب.
في الآخر نخرج بتقرير واحد: **جاهزون للإطلاق، أو ما الذي بقي.**

**النطاق:** التطبيق (أندرويد، على جوال المالك)، الموقع العام، لوحة التحكم، الخادم.
**خارج النطاق الآن (مرحلة الإطلاق):** ربط الواتساب الحقيقي، السيرفر والدومين، متجر Google Play،
الآيفون. نستعمل أرقاماً وهمية والرمز يُضبط من الخادم في وضع التطوير.

| # | الخطوة | |

**التقرير النهائي يقول:**
1. **الحكم:** جاهزون للإطلاق / جاهزون بشروط / غير جاهزين.
2. **ما نجح** — بالأرقام لكل مرحلة.
3. **ما صُلّح أثناء الفحص** — ما كان، وكيف صُلّح، وأنه أُعيد اختباره.
4. **ما بقي** — مشكلة، وأثرها، ومتى تُحل.
5. **ما يحتاج قرارك** — مثل سياسة وثائق الصيدليات، النصوص القانونية، أرقام الطوارئ.
6. **قائمة مرحلة الإطلاق** — السيرفر، الدومين، الواتساب، المفاتيح، المتجر — بالترتيب.
