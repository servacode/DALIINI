### ٣ — الموقع العام

قسم افتتاحي بالبحث و«أقرب مناوب الآن» وخريطة حيّة، وبطاقات مضغوطة على الجوال، وصفحة منشأة غنية
(صور، خريطة، تقييم، شريط إجراءات ثابت)، وقسم للتطبيق وللمالكين، وصفر عيوب بصرية بالوضعين.
بوابة المالك على الويب **تُعرض للقرار** عند بدء هذه المرحلة.

### ٤ — لوحة التحكم v2

التصميم الجديد، وجداول احترافية (ترقيم، فرز، تصفية، أعمدة)، ومحرر المنشآت، وخريطة المنشآت، ورسوم
بيانية، ومحرر الأدوار، والتحقق بخطوتين، وصحة النظام (الرموز، البوت، الإشعارات، النسخ الاحتياطي).

### ٥ — الأندرويد v2

التصميم الجديد وحركة مدروسة، وBaseline Profile، وخدمة تُبقي الملاحة تعمل عند قفل الشاشة، وترقيم
إصدارات آلي، وتحديث داخل التطبيق، وفحص كامل على جهاز حقيقي.

### ٦ — البنية الإنتاجية

خادم VPS بـ Docker Compose وCaddy (شهادات تلقائية) وCloudflare، وتخزين S3، ونسخ احتياطي مع تمرين
استرجاع، وخرائط ومسارات ذاتية الاستضافة، ومراقبة، ونشر آلي من GitHub، واختبار حمل. ملفات Render
تُستبدل هنا بإعداد الخادم، مع اختبار الإقلاع الذي يغطيها اليوم.

### ٧ — المحتوى والإطلاق

النصوص القانونية (أكتب المسودة وتعتمدها)، وبريد الدعم، ومواد المتجر، وتجربة مغلقة على Play، ثم
النشر العام ومراقبة الأسبوع الأول.

### ٨ — الآيفون

نقل الطبقات المشتركة إلى KMP، ثم تطبيق iOS بـ Compose Multiplatform، ثم App Store.

## العمل المحلي

```bash
pnpm install
pnpm stack:up      # قاعدة البيانات والتخزين والخادم والعمّال
pnpm stack:seed    # مشغّلون ومالك ودليل تجريبي
pnpm dev:admin     # http://localhost:3000
pnpm dev:web       # http://localhost:3001
```
