# Directory Android

Native Kotlin + Jetpack Compose client for Directory Platform V3.

## Toolchain

- Android Gradle Plugin 9.4.0
- Gradle 9.6.0 (wrapper must be generated by a trusted Gradle installation)
- JDK 17+ supported by AGP; CI should pin JDK 17 for reproducibility
- compileSdk 36 / targetSdk 36 / minSdk 24

## Architecture

Composable → ViewModel → UseCase → Repository → RemoteDataSource / LocalDataSource.

The OpenAPI generated Kotlin client is an upstream P10 artifact. Android code must not hand-author
transport DTOs to bypass that contract. `GeneratedApiClientBoundary` exists only as the integration
boundary until P10 can run in a Django-capable environment.

## Session

- access token: memory only;
- refresh token: AES/GCM ciphertext protected by Android Keystore key;
- refresh rotation: `Mutex` coordinated;
- no password persistence;
- no refresh token in DataStore or plain SharedPreferences.

## Build

Once Android SDK and a trusted Gradle 9.6 installation are available:

```bash
gradle wrapper --gradle-version 9.6.0
./gradlew test
./gradlew lint
./gradlew :app:assembleDebug
```

Do not commit signing keys or `local.properties`.
