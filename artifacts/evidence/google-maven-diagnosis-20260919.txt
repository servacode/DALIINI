Conclusion
  Not DNS, not a proxy, not TLS interception, not Gradle, not the cache. Google's download
  service answers this network's address with 404 for Android developer content — the Maven
  repository, the SDK manifest, platform-tools — while it serves other content from the same
  host (the Linux signing key) to the same client. That selective refusal matches the way
  Google restricts Android developer downloads by the client's location; which rule applies to
  this address is Google's to say, and it cannot be seen from here.
  Classification: NETWORK_ENVIRONMENT_FAILURE. It is not artifact-not-found, and nothing on
  this machine or in the project can change it. Only a different egress network can.
