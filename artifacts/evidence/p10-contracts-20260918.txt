================================================================================
5. ERROR CONTRACT
================================================================================
The project has no custom DRF EXCEPTION_HANDLER, so the runtime produces exactly two
shapes and both are described as they are:

  DetailError          {"detail": "..."}                     401, 403, 404, 429
  DomainError          {"error": {"code": ..., "details": ...}}  400, 409
  FieldValidationError {"<field>": ["<message>", ...]}       400

08-API-CONTRACT specifies one richer envelope with code, message, details and
requestId. The runtime does not emit it. Documenting the specified envelope would have
made the contract lie, so the divergence is recorded as a defect instead.

11. DRIFT GATE
================================================================================
Before: `git diff --exit-code -- openapi/schema.yaml` on an untracked file. git diff
ignores untracked paths, so the gate reported success on a contract that did not exist.

After: refuses to run unless both canonical files are tracked, compares blob hashes
across a regeneration, and independently verifies the recorded digest against the
document on disk. CI additionally regenerates all three clients and fails if they
differ from what is committed.
